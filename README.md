# Static Webpage Builder

A lightweight static webpage builder demo with a simple editor panel and live preview.

## Features

- Edit site name, hero heading, supporting text, CTA copy, and color
- Live preview updates instantly
- No build step required

## Run it locally

Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Files

- `index.html` – app structure
- `styles.css` – page styling
- `script.js` – live preview logic
